# Font assets

The storefront includes these original, unmodified font files:

- `compagnon-medium.otf` — Compagnon Medium by Sebastien Riollier / Velvetyne Type Foundry, licensed under the SIL Open Font License 1.1.
- `semplicita-book.otf` — Semplicita Modern Book, digital porting by Leonardo Di Lena, licensed under CC BY-ND 3.0.
- `semplicita-book-italic.otf` — Semplicita Modern Book Italic, digital porting by Leonardo Di Lena, licensed under CC BY-ND 3.0.

The Semplicita files must remain unmodified. Full terms and attribution are in the repository's `LICENSES` directory.

Other font binaries remain excluded from the public repository unless their redistribution terms are separately verified. `kalakala-regular.otf` is not used by the site and is not included.
