# Local font assets

The stylesheet expects these licensed font files in this directory:

- `compagnon-medium.otf`
- `semplicita-book.otf`
- `semplicita-book-italic.otf`

The binaries are intentionally excluded from the public Git repository until their licenses are confirmed to permit source redistribution. Copy legitimately licensed files into this directory for local development and include them through the approved private asset or deployment process in production.

`kalakala-regular.otf` is not currently used by the site.
